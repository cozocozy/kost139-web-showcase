## 📌 Deskripsi Singkat
Aplikasi web promosi kost interaktif yang menghubungkan calon penyewa dan pemilik kost melalui fitur seperti fasilitas, galeri fasilitas, lokasi kost,dan One-Click WhatsApp CTA.

## 🛠 Tech Stack
* **Frontend & Framework:** Next.js
* **Styling / UI:** Tailwind CSS
